# Ресурси каталогу рун

`runes/<id>/` містить:

- `rune.svg` — окреме векторне накреслення на прозорому тлі, без залежності від шрифтів;
- `description.md` — опис російською, як у вихідному PDF, із сімома розділами;
- `rune.json` — стабільний ID, символ Unicode, опис, джерела зі сторінками, сегменти геометрії та статус перевірки;
- `description.source-2.md` — друга версія опису, якщо в PDF є повторний розділ;
- `rune.extended.svg` — додатковий варіант Інґуз зі спірної ділянки таблиці, без автоматичного прив’язування до літер.

`manifest.json` — список записів і шляхів для майбутнього імпортера БД. `preview.html` — локальна галерея всіх основних SVG. SQL та міграції тут не створюються: це незалежні seed-ресурси для майбутньої схеми PostgreSQL.

## Походження

23 основні описи витягнуто з `starter info/АНСУЗ.docx.pdf`. Прибрано переноси рядків PDF, додано Markdown-заголовки та списки; текст не перекладено й не скорочено. Для Манназ та Інґуз основним тимчасово обрано перше входження, наступне збережено окремо. Не змішувати обидва входження під час імпорту без редакторського рішення.

Опис Ейваз підготовлено окремо в `editorial/eihwaz.md` за структурою інших описів. Це оригінальна редакторська символічна інтерпретація. Історичні джерела підтверджують зв’язок назви з тисом; психологічні розділи — авторська адаптація для цього каталогу, а не переклад історичного тексту чи діагностика особистості. Джерела й типи використання перелічені в `runes/eihwaz/rune.json`.

SVG створено вручну як геометрію, переважно за наданою таблицею. Це нормалізовані векторні еталони, а не точне трасування пікселів. Кожен сегмент має стабільний ID та координати в JSON для майбутньої перевірки складання формул. Інґуз відокремлено від Йери; Ейваз `ᛇ` та Еваз `ᛖ` — різні записи. Геометрія потребує візуального приймання перед production-використанням. Відповідності літерам навмисно не включено: їх версійований профіль буде окремим ресурсом.

## Відтворення та перевірка

Потрібні Python 3.10+ і `pypdf` (для перебудови). Команди з кореня проєкту:

```text
python scripts/build_rune_resources.py
python scripts/build_rune_resources.py --check
```

Перебудова перезаписує згенеровані файли. Редактуру Ейваз робити в `editorial/eihwaz.md`; геометрію — у `RUNES` скрипта. Перевірка без перебудови використовує лише стандартну бібліотеку Python: кількість записів, сім розділів, джерела, координати та відповідність SVG ↔ JSON. Вона не замінює візуальну оцінку.
