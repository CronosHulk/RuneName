# RuneName

Простий Telegram-бот: ім’я українською або російською → опис за п’ятьма
категоріями та перелік використаних рун. Повтори рун видаляються кодом до
запиту. NVIDIA отримує повні описи тільки потрібних рун. На кожне ім’я —
один окремий запит.

## Запуск

Потрібен Python 3.10+. Сторонні пакети не потрібні.

1. Створіть бота через @BotFather і вставте токен у `TELEGRAM_BOT_TOKEN` у `.env`.
2. Заповніть `NVIDIA_API_KEY`. Вже наявний ключ збережено.
3. З кореня проєкту:

```powershell
python -m runename.bot --check
python -m runename.bot
```

Якщо системний Python недоступний, у цьому workspace підготовлений переносний:

```powershell
./.tools/python/python.exe -m runename.bot --check
./.tools/python/python.exe -m runename.bot
```

Бот працює, доки процес запущений; зупинка — Ctrl+C. Підтримуються особисті
повідомлення, одна копія бота. База, черги, AWS, вебсервер і генерація картинок
не використовуються.

## Повідомлення

- `Максим` або `Ірина` — опис **російською за замовчуванням**, незалежно від мови імені чи Telegram.
- `/uk Ірина` — опис українською.
- `/ru Ирина` — опис російською.
- `/start` або `/help` — підказка.

У відповіді: ім’я, символи та назви унікальних рун, «Характер и особенности»,
«Сильные стороны», «Движение к результату», «Тень», «Главный ресурс» (або
українські відповідники). Історія й результати не записуються на диск.
Назви рун наразі беруться російською з джерельного каталогу.

Межі MVP: обробка послідовна; довгий запит затримує наступний. Після перезапуску
незавершене повідомлення може надійти повторно — постійного сховища для
дедуплікації Telegram немає. Помилки NVIDIA або змішана мова дають повідомлення
про тимчасову недоступність, без автоматичного нового запиту. Перевірки формату
не доводять змістової точності символічного портрета.

Правила `author-v1` попередні: И/І → Іса, Й → Йера, Ї → Йера + Іса,
Є → Йера + Еваз, Ю → Йера + Уруз, Т → Тейваз; Ь/Ъ й апостроф не утворюють рун.
Невідомі символи повертають помилку. Це правила продукту, не історичний стандарт.

## Перевірки

```powershell
python -m unittest discover -s tests -v
python scripts/build_rune_resources.py --check
```

Код бота: `runename/bot.py`; правила імен: `runename/names.py`; сценарій:
`runename/name_description.py`; NVIDIA: `runename/nvidia.py`.
Промпти: `prompts/name_categories_ru.txt` і `prompts/name_categories_uk.txt`.
Живий російський сценарій перевірено. Українська генерація цієї моделі поки
нестабільна: мовні домішки відхиляються з пропозицією повторити пізніше.
Каталог: [db_resources/README.md](db_resources/README.md).

Збережені артефакти й попередні експерименти не беруть участі у виконанні бота.
Cloudflare видалено. Ключі, переносний Python та артефакти виключено з Git.
