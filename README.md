# RuneName

Сервіс створення руничної формули і стислої символічної інтерпретації імені.

Планований стек: Python / FastAPI, React / TypeScript, PostgreSQL + pgvector,
SQLAlchemy та Alembic. Спільне ядро для вебінтерфейсу й Telegram-бота;
гексагональна архітектура. Розгортання на VPS та AWS.

Зараз підготовлені план і ресурси каталогу; сам застосунок ще не реалізовано.

- [План проєкту](PROJECT_PLAN.md)
- [Архітектурні правила](AGENTS.md)
- [Каталог із 24 рун](db_resources/README.md)
- [Галерея SVG](db_resources/preview.html) — відкрити локально в браузері

## Перевірка ресурсів

```sh
python scripts/build_rune_resources.py --check
```

Для перебудови потрібні `pypdf` і локальний вихідний PDF. Деталі —
у [документації ресурсів](db_resources/README.md).

Вихідні PDF, фото та референси з папок `starter info/` і `what we want/`
не публікуються. Каталог містить підготовлені описи, їх походження й створені SVG.
Секрети, локальні налаштування та користувацькі результати виключені через `.gitignore`.
